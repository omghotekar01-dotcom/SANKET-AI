# SANKET AI

Real-Time Multimodal Indian Sign Language Interpreter for Hacktopia 2026.

This repository is being structured around the submitted Peaky Coders concept: multimodal ISL understanding (hands + face + body + motion + context), confidence-aware interpretation, two-way communication, accessibility outputs, real-time calling overlays, emergency communication, and safe in-app action control.

Detailed implementation prompts and build specifications are maintained under `prompts/` on the active development branch before merging into `main`.
